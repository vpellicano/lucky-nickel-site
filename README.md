# Lucky Nickel Company site

Mobile-first prelaunch site for [luckynickelcompany.com](https://luckynickelcompany.com/).

The repository is the website source of record. Bex's Lucky Nickel Google Drive materials govern brand, products, formulas, claims, and launch decisions.

## Publishing

Production is an S3 origin behind CloudFront. Use the existing private deployment record and intentionally publish only the static site files. GitHub Pages and GitHub Actions are not the production path.

## Content rules

- Flavor first, symbolism second.
- No health, spiritual, or guaranteed-outcome claims.
- Do not imply that placeholder people or photographers endorse the company.
- Replace placeholder photographs with original founder and product images before commerce.
- Every saleable product is commercially produced and lot-coded by a qualified food co-manufacturer or co-packer.
